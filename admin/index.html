🥖 Administration du site

Modifiez le contenu, glissez les photos, publiez. Le site se met à jour automatiquement en une minute.

Clé d'accès (une seule fois)

Il faut une clé GitHub pour publier. Elle reste uniquement sur cet ordinateur/navigateur, jamais envoyée ailleurs.

Comment obtenir cette clé ?
  1. Aller sur github.com/settings/tokens/new (connecté avec le compte GitHub qui a accès au dépôt).
  2. Note : "Admin site Baguette" — Expiration : au choix (ex. 1 an).
  3. Cocher uniquement la case repo.
  4. Cliquer "Generate token" en bas, puis copier la clé (elle ne sera montrée qu'une fois) et la coller ci-dessus.
